ReBith Guitar FX

Your Guitar. Your Sound. Your Studio.

ReBith Guitar FX is an Android guitar effects application designed to bring essential guitar tones and a flexible effects chain to your mobile device.

Vision

Build a portable guitar studio with a modern interface, responsive controls, and real-time audio processing.

Core Features

- Pedalboard Mode — Arrange and control guitar effects.
- Amp Studio Mode — Shape your tone with amplifier and cabinet simulations.
- Noise Gate — Reduce unwanted background noise.
- Drive — Boost, overdrive, and distortion tones.
- Amp & Cab Simulation — Clean, vintage crunch, British rock, and modern high-gain tones.
- Equalizer — Shape the frequency response.
- Delay — Add echoes and rhythmic depth.
- Reverb — Create room, hall, and ambient spaces.
- Presets — Save and recall guitar tones locally.
- Offline-First — Designed to work without requiring a cloud account.

Technology

- Kotlin and Jetpack Compose for the Android interface.
- C++ and Oboe for the planned low-latency audio engine.
- JNI for communication between Kotlin and native audio code.
- Local storage for presets and preferences.
- GitHub Actions for automated Android builds.

Audio Connectivity

The planned audio workflow uses a compatible USB OTG audio interface to receive the guitar signal and send processed audio to headphones or speakers.

Actual latency, USB compatibility, and audio processing performance must be validated on supported devices.

Project Status

Early development. The initial project structure and audio engine are still being built. Features listed above represent the project direction and are not all implemented yet.
